THE FIRST 50 DAYS

Building the capability, one layer at a time

Each phase of the challenge added a layer of capability — not in isolation, but as groundwork the capstone would eventually draw on directly.

FOUNDATIONS
AI fundamentals & effective prompting
Understanding how to communicate intent clearly and get reliable output — the same instinct later used to write the structured JSON prompt that drives RecoverIQ's scenario generation.
REASONING
Reasoning & research workflows
Practicing how to break a problem down and verify an answer rather than accept the first output — the habit that later meant reading actual server logs instead of guessing at bugs.
SYSTEMS
Automation & product thinking
Learning to see a workflow as a system with inputs, failure modes, and a user on the other end — directly shaping RecoverIQ's Day 1 scoping decisions.
BUILDING
Increasingly sophisticated AI projects
Each project a step up in complexity, building the confidence to attempt a full-stack, AI-integrated application solo.
EXPANDING
Multimodal AI & knowledge systems
Working with AI beyond text — context that informed how RecoverIQ's own data model (runbooks, structured scenarios, audit trails) was designed to hold meaning, not just fields.
ADVANCED
Autonomous agents & multi-agent collaboration
Understanding how AI systems plan, act, and hand off work — the exact mental model behind treating Claude as a pair programmer across a real ten-day build.
DAYS 51–60 · THE CAPSTONE

Everything converged into RecoverIQ

A full software development lifecycle — requirements, design, implementation, QA, launch — built solo in ten days, applying every layer of the previous fifty.

Product thinking
Scoped "all three" drill modes down to one defensible v1.0 on Day 1.
Full-stack build
.NET 8 API, React frontend, EF Core, JWT auth — implemented and deployed.
AI integration
Live Gemini API integration, debugged through three model deprecations in real time.
Debugging discipline
Diagnosed a production-only auth bug via Render server logs, not guesswork.
Security judgment
Caught a leaked secrets file, rotated the key, and documented the fix honestly.
Release readiness
A formal QA pass — 12 issues found and fixed — before calling it launch-ready.
